# கிறுக்கல் (Kirukkal)

A Tamil draw-and-guess multiplayer game (skribbl.io style). Guess in Tamil or type English letters (Tanglish) and they convert live.

```
npm install
npm start      # http://localhost:3000
npm test
```

Deploy: Render web service (see `render.yaml`) — it needs WebSocket support, which Render web services have by default.
